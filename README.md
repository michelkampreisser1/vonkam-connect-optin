# preforeclosure.miami

Site of Vonkam Technologies LLC. Vite + React + Tailwind, deployed on Vercel (project `preforeclosure-site`, team vonkams-projects).

The contact form posts to `https://www.vonkam.technology/api/website-leads` (vonkam-data-frontend), which stores the lead in `website_leads`. This site sends no SMS, email or calls.
